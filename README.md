# Espacio de trabajo universitario (plantilla)

Estructura, skills y convenciones para producir actividades e informes con
Claude Code. No contiene datos personales.

## Primer uso

1. Clona este repo y abre Claude Code **desde la raíz** del proyecto.
2. Suelta los archivos del campus en `_bandeja-entrada/`.
3. Pide `/nueva-actividad` para crear la carpeta y la fila en `ESTADO.md`.
4. Redacta con `redaccion-natural` y `plantilla-informe-docx`.
5. Antes de entregar, corre `cumplimiento-rubrica`; luego `/cerrar-actividad`.

Detalles de convenciones en `CLAUDE.md`.
